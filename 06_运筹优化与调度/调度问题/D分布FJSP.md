│   │       ├── 存在多个工厂
│   │       ├── 不同工厂拥有不同机器
│   │       ├── 先决定工件分配到哪个工厂
│   │       └── 再安排工厂内部的工序与机器

│   ├── 7_基本限制
│   │   ├── 工序必须按照工艺顺序执行
│   │   ├── 工序只能选择具备加工能力的机器
│   │   ├── 一台机器同一时间只能加工一道工序
│   │   ├── 一道工序只能分配给一台机器
│   │   ├── 工件只能进入允许选择的工厂
│   │   ├── 跨工厂加工必须考虑运输时间
│   │   └── 工厂和机器不能超过自身产能
│   │
│   ├── 8_完整运行流程
│   │   └──
│   │       读取工厂、机器和工件数据
│   │         ↓
│   │       建立多个工厂的生产模型
│   │         ↓
│   │       将工件分配到不同工厂
│   │         ↓
│   │       为各工序选择机器
│   │         ↓
│   │       确定各机器的加工顺序
│   │         ↓
│   │       计算开始时间和结束时间
│   │         ↓
│   │       检查工序、机器和工厂约束
│   │         ↓
│   │       计算完工时间、负载、成本和能耗
│   │         ↓
│   │       调整工厂分配或工厂内部计划
│   │         ↓
│   │       满足停止条件
│   │         ↓
│   │       输出分布式生产计划
│   │
