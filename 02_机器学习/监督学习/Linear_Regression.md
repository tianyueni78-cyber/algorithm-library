# Linear Regression
# 1. 一句话说明它是什么

> `Linear Regression（线性回归）` 是一种用一条直线或一个平面概括数据变化规律的方法，主要用于预测价格、时间、销量等连续数值。

本文讨论机器学习和统计分析中的线性回归。

# 3. 人和算法分别负责什么

```text
现实问题
  ↓
人需要完成的工作
  ├── 明确要预测哪个数值
  ├── 提供历史案例及真实结果
  ├── 选择预测时可以获得的信息
  └── 检查直线关系是否基本合理
  ↓
算法需要完成的工作
  ├── 寻找各项输入的影响大小
  ├── 调整预测公式，使整体误差尽量小
  └── 使用公式预测新案例
  ↓
最终结果
  ├── 预测数值
  └── 各项输入与结果的关系
```

- **人提供**：历史数据、要预测的数值、可用输入。
- **算法完成**：寻找一条最贴近历史数据的直线或平面。
- **算法返回**：预测公式、预测数值和误差指标。

它不能自动证明“某项输入导致了某个结果”。

# 5. 从抽象现实问题中提取模型的方法

```text
什么事情需要决定？
→ 要预测的连续数值

什么情况绝对不允许？
→ 禁用数据、输出范围或业务限制

什么结果算更好？
→ 预测值与真实值的差距更小

哪些信息在决策前已经知道？
→ 可以用于预测的输入数据

哪些信息会随着过程变化？
→ 时间、价格、需求等动态信息
```

## 关键词对应关系

| 自然语言关键词 | 对应内容 |
|---|---|
| “预测多少、预计时间、价格” | 输出数值 |
| “根据、受……影响” | 输入特征 |
| “实际价格、实际销量” | 历史正确答案 |
| “每增加一个单位” | 输入与输出的线性关系 |
| “误差尽量小、预测准确” | 评价目标 |
| “必须非负、不能超过” | 业务限制 |

这里的“特征”就是用于预测的信息，例如面积、房龄和位置。

# 6. 总体输入与输出

| 类型 | 内容 | 示例 |
|---|---|---|
| 原始业务输入 | 历史业务记录 | 房屋面积、房龄、成交价 |
| 建模后的算法输入 | 数值表和真实答案 | `X=面积和房龄，y=房价` |
| 算法内部数据 | 每项输入的影响系数 | 每增加1平方米，价格增加多少 |
| 最终业务输出 | 新案例的预测数值 | 预测房价120万元 |

简单形式可以写成：

```text
预测结果 = 基础值 + 输入1的影响 + 输入2的影响 + …
```

# 9. 每个模块的输入、输出和构成

## 01_Problem_Data

### 作用

确定预测对象和可用信息。

### 输入

- 现实问题
- 历史记录
- 业务要求

### 内部构成

```text
Problem_Data
├── Prediction_Target
├── Input_Features
└── Business_Rules
```

### 处理过程

1. 确定要预测哪个数值。
2. 选择预测前能获得的信息。
3. 排除泄露答案的数据。
4. 确定误差的业务影响。

### 输出

- 预测目标
- 输入特征
- 业务规则

### 是否需要用户自己实现

**通常需要自己实现。**

---

## 02_Data_Preparation

### 作用

把业务记录整理成可以计算的表格。

### 输入

- 原始数据
- 特征列表
- 真实结果

### 内部构成

```text
Data_Preparation
├── Data_Cleaning
├── Category_Encoding
└── Dataset_Split
```

### 处理过程

1. 处理缺失值和错误记录。
2. 将需要的文字类别转换成数字。
3. 检查异常值。
4. 划分训练集和测试集。

### 输出

- 训练数据
- 测试数据

### 是否需要用户自己实现

**两者都可以。**库提供处理工具，人负责判断数据是否合理。

---

## 03_Model_Training

### 作用

找到整体预测误差较小的公式。

### 输入

- 训练特征
- 历史真实结果

### 内部构成

```text
Model_Training
├── Coefficient_Estimation
├── Error_Minimization
└── Model_Output
```

### 处理过程

1. 给每项输入分配一个影响系数。
2. 用公式预测训练数据。
3. 比较预测值和真实值。
4. 调整系数，使总体误差尽量小。

### 输出

- 基础值
- 各特征的影响系数
- 训练好的模型

### 是否需要用户自己实现

**通常由算法库提供。**

---

## 04_Prediction

### 作用

用训练好的公式预测新案例。

### 输入

- 训练好的模型
- 新案例的特征

### 内部构成

```text
Prediction
├── Input_Check
├── Formula_Calculation
└── Result_Output
```

### 处理过程

1. 按训练时的方式整理新数据。
2. 将输入代入预测公式。
3. 输出预测数值。

### 输出

- 预测值

### 是否需要用户自己实现

**计算由库提供；业务格式转换通常由用户实现。**

---

## 05_Evaluation

### 作用

检查预测是否足够准确、稳定。

### 输入

- 测试数据
- 真实结果
- 预测结果

### 内部构成

```text
Evaluation
├── Error_Metrics
├── Residual_Check
└── Business_Validation
```

“残差”就是每个案例的预测值与真实值之差。

### 处理过程

1. 计算测试数据的预测值。
2. 比较预测值和真实值。
3. 检查是否经常高估或低估。
4. 查看极端数据是否严重影响模型。

### 输出

- 平均误差
- 模型拟合程度
- 异常案例

### 是否需要用户自己实现

**计算可由库完成；业务判断需要人完成。**

# 11. 用户需要实现什么

## 通常需要自己实现

- 定义预测目标；
- 收集历史数据；
- 选择输入特征；
- 检查数据质量；
- 防止使用未来信息；
- 选择误差指标；
- 判断线性关系是否合理；
- 处理业务限制。

## 通常由算法库或求解器提供

- 计算影响系数；
- 寻找误差较小的公式；
- 执行预测；
- 计算常见评价指标。

`scikit-learn`侧重预测；`statsmodels`还提供更多统计分析结果。两者都不能替代业务判断。

# 12. 它真正帮我解决什么

| 问题 | 线性回归的边界 |
|---|---|
| 帮助理解问题吗？ | 可以显示各项输入与结果的关系，但不自动证明因果。 |
| 帮助建立模型吗？ | 可以建立简单预测公式；输入和目标仍由人定义。 |
| 帮助搜索答案吗？ | 会寻找合适的系数，但不是排产等组合优化算法。 |
| 帮助预测结果吗？ | 可以，这是主要用途。 |
| 帮助做连续决策吗？ | 通常不能，只对一次输入给出一次预测。 |
| 帮助验证解是否可行吗？ | 不能保证业务可行，需要额外规则检查。 |

例如，它可能预测库存需求为负数。计算没有失败，但业务结果不合理，需要人处理。

# 13. 适用与不适用场景

| 比较适合 | 原因 |
|---|---|
| 房价、销量、工时预测 | 输出是连续数值 |
| 输入变化与结果大致同步变化 | 符合直线关系 |
| 需要容易解释的模型 | 每个系数含义较直观 |
| 需要一个简单基准模型 | 训练快，容易检查 |

| 不太适合 | 原因 |
|---|---|
| 判断类别 | 通常应使用逻辑回归等分类方法 |
| 关系明显弯曲或分段 | 一条直线难以描述 |
| 输入之间关系非常复杂 | 简单公式表达能力不足 |
| 异常值很多 | 少量极端数据可能明显影响结果 |
| 需要证明因果关系 | 预测关系不等于因果关系 |
| 远离历史范围进行预测 | 直线外推可能非常不可靠 |

# 14. 与相近算法比较

| 对比项 | 线性回归 | 逻辑回归 | 决策树回归 |
|---|---|---|---|
| 输入形式 | 表格特征 | 表格特征 | 表格特征 |
| 输出形式 | 连续数值 | 类别概率 | 连续数值 |
| 是否需要历史答案 | 需要 | 需要 | 需要 |
| 如何学习 | 学习一个线性公式 | 学习分类概率公式 | 学习分段判断规则 |
| 是否保证业务可行 | 不保证 | 不保证 | 不保证 |
| 是否追求绝对最优业务方案 | 否 | 否 | 否 |
| 关系形式 | 直线或平面 | 平滑的分类边界 | 分段、非线性 |
| 适用问题 | 价格、销量、时间 | 是否违约、是否故障 | 复杂的数值关系 |

注意：逻辑回归虽然名字包含“回归”，主要用于分类。

# 15. 可以与其他算法融合的位置

## 特征提取与线性回归

```text
特征提取算法
  ↓ 输出可用数值特征
线性回归
  ↓ 输出预测数值
业务系统
```

- **融合位置**：数据准备。
- **为什么融合**：原始文本、日期等不能直接使用。
- **前者输出**：整理后的数字。
- **线性回归接收**：数值特征。
- **解决问题**：让复杂数据进入简单预测公式。

## 正则化与线性回归

“正则化”就是限制公式不要过度依赖某些输入。

```text
Ridge或Lasso限制
  ↓ 控制系数大小
线性回归
  ↓ 输出更稳定的预测公式
```

- **融合位置**：模型训练。
- **为什么融合**：特征很多或彼此重复时，普通线性回归可能不稳定。
- **限制方法输出**：受约束的系数。
- **解决问题**：减少过度拟合，提高稳定性。

## 线性回归与优化算法

```text
线性回归
  ↓ 预测需求、成本或时间
调度优化算法
  ↓ 生成满足约束的方案
最终决策
```

- **融合位置**：优化算法的输入或目标评价。
- **为什么融合**：线性回归负责预测，不负责安排资源。
- **线性回归输出**：预测需求或成本。
- **优化算法接收**：预测结果和业务约束。
- **解决问题**：从“预测会发生什么”转为“决定应该怎么做”。

# 16. 最小示例

## 原始问题

根据学习时间预测考试成绩。

## 输入数据

| 学习时间 | 实际成绩 |
|---:|---:|
| 1小时 | 50分 |
| 2小时 | 60分 |
| 3小时 | 70分 |

## 变量或状态

- 输入：学习时间；
- 输出：考试成绩。

## 规则或约束

- 只使用学习时间；
- 历史数据大致呈直线变化；
- 预测不能被解释为学习时间一定导致成绩提高。

## 目标

让预测成绩与实际成绩的差距尽量小。

## 算法执行过程

从数据可以得到：

```text
每多学习1小时，成绩大约增加10分
学习0小时对应的基础值约为40分
```

因此预测公式为：

```text
预测成绩 = 40 + 10 × 学习时间
```

新学生学习4小时：

```text
预测成绩 = 40 + 10 × 4 = 80分
```

## 输出结果

```text
预测成绩：80分
```

这个例子可以手工检查，但真实成绩还会受到基础、题目难度等因素影响。

# 17. 一句话总结

> 人负责定义预测对象、选择输入并准备历史数据；`Linear Regression`负责寻找整体误差较小的线性关系；最终输出预测数值及各项输入的影响系数。
