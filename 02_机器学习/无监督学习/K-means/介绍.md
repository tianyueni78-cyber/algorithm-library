# K-means
# 1. 一句话说明它是什么

> `K-means` 是一种把相似对象自动分成指定数量群组的方法，主要用于发现数据中没有预先标注的群体。

K-means属于**无监督学习**：训练数据不需要提供正确分组答案。

# 3. 人和算法分别负责什么

```text
现实问题
  ↓
人需要完成的工作
  ├── 选择用于比较对象的信息
  ├── 统一不同信息的数值尺度
  ├── 指定群组数量K
  └── 解释每个群组的业务含义
  ↓
算法需要完成的工作
  ├── 设置K个初始群组中心
  ├── 把对象分给最近的中心
  ├── 更新每个群组的中心
  └── 重复分配和更新
  ↓
最终结果
  ├── 每个对象的群组编号
  └── 每个群组的中心
```

- **人提供**：对象特征、群组数量K和基本参数。
- **算法完成**：反复调整分组和群组中心。
- **算法返回**：群组编号、群组中心和组内距离。

它不能自动确定群组的业务名称，也不能保证每次都得到完全相同的最佳分组。

# 5. 从抽象现实问题中提取模型的方法

```text
什么事情需要决定？
→ 每个对象属于哪个群组

什么情况绝对不允许？
→ 错误数据、禁止使用的信息、不同单位直接比较

什么结果算更好？
→ 同组对象彼此接近，对象靠近所属群组中心

哪些信息在决策前已经知道？
→ 每个对象可以用于比较的特征

哪些信息会随着过程变化？
→ 新增对象、客户行为或设备状态
```

| 自然语言关键词 | 对应内容 |
|---|---|
| “分成几组” | K值 |
| “相似、接近” | 距离 |
| “典型对象、平均特征” | 群组中心 |
| “自动分组、客户分层” | 聚类输出 |
| “金额、频率、位置” | 输入特征 |

# 6. 总体输入与输出

| 类型 | 内容 | 示例 |
|---|---|---|
| 原始业务输入 | 对象的原始记录 | 客户消费金额、购买次数 |
| 建模后的算法输入 | 统一尺度的数字特征和K值 | 每行代表一个客户，K=3 |
| 算法内部数据 | 群组中心、距离、当前编号 | 客户A距离中心1最近 |
| 最终业务输出 | 群组编号和群组中心 | 客户A属于群组1 |

K-means不需要历史正确答案。

# 7. 完整运行流程

```text
现实对象
  ↓
选择比较特征
  ↓
清理并统一数据尺度
  ↓
指定群组数量K
  ↓
生成K个初始中心
  ↓
把对象分给最近中心
  ↓
重新计算群组中心
  ↓
重复直到结果基本不变
  ↓
输出并解释群组
```

# 9. 每个模块的输入、输出和构成

## 01_Problem_Data

### 作用

确定分组对象、比较特征和群组数量。

### 输入

- 原始业务数据
- 业务分组需求

### 内部构成

```text
Problem_Data
├── Input_Features
├── Cluster_Count
└── Distance_Rule
```

### 处理过程

1. 确定需要分组的对象。
2. 选择能够代表相似性的特征。
3. 设置群组数量K。

### 输出

- 特征列表
- K值
- 距离方式

### 是否需要用户自己实现

**通常需要自己完成。**

---

## 02_Data_Preparation

### 作用

把业务记录转换成可以公平比较的数字。

### 输入

- 原始数据
- 特征列表

### 内部构成

```text
Data_Preparation
├── Missing_Value_Handling
├── Category_Encoding
└── Feature_Scaling
```

### 处理过程

1. 处理缺失和错误数据。
2. 必要时将文字转换成数字。
3. 统一不同特征的数值尺度。

### 输出

- 处理后的特征表
- 数据转换规则

### 是否需要用户自己实现

**两者都可以。**库提供工具，人负责判断处理是否合理。

---

## 03_Clustering

### 作用

反复调整对象分组和群组中心。

### 输入

- 处理后的特征表
- K值
- 初始中心设置

### 内部构成

```text
Clustering
├── Center_Initialization
├── Sample_Assignment
├── Center_Update
└── Stop_Check
```

### 处理过程

1. 生成K个初始中心。
2. 将每个对象分给最近的中心。
3. 根据组内对象重新计算中心。
4. 重复以上过程，直到结果基本不变。

### 输出

- 群组编号
- 群组中心
- 组内距离统计

### 是否需要用户自己实现

**通常由K-means算法库提供。**

---

## 04_Result_Validation

### 作用

检查K值和分组结果是否合理。

### 输入

- 不同K值的聚类结果
- 群组中心
- 原始业务数据

### 内部构成

```text
Result_Validation
├── Cluster_Statistics
├── K_Comparison
└── Business_Interpretation
```

### 处理过程

1. 比较不同K值。
2. 查看各群组大小和中心。
3. 检查是否存在过小或难以解释的群组。
4. 根据业务特征命名群组。

### 输出

- 推荐K值
- 最终群组
- 群组业务名称

### 是否需要用户自己实现

**统计可由库提供；K值选择和业务解释由人完成。**

# 12. 它真正帮我解决什么

| 问题 | K-means的边界 |
|---|---|
| 帮助理解问题吗？ | 能显示数据中的主要群体，但群组含义需要人解释。 |
| 帮助建立模型吗？ | 能建立分组结构，输入特征和K值由人定义。 |
| 帮助搜索答案吗？ | 会反复搜索较好的群组中心，但不保证得到全局最佳结果。 |
| 帮助预测结果吗？ | 可把新对象分给最近中心，但不预测故障、销量等业务答案。 |
| 帮助做连续决策吗？ | 不能。 |
| 帮助验证解是否可行吗？ | 不能保证业务正确，只提供分组结果。 |

# 13. 适用与不适用场景

| 比较适合 | 原因 |
|---|---|
| 客户分群 | 可以得到群组中心和典型特征 |
| 已大致知道群组数量 | K值需要提前设置 |
| 群组大小和密度相近 | 符合K-means的分组特点 |
| 数值型表格数据 | 容易计算对象与中心的距离 |
| 需要给新对象快速分组 | 只需寻找最近中心 |

| 不太适合 | 原因 |
|---|---|
| 不知道应分成几组 | 必须选择K值 |
| 群组形状弯曲或不规则 | 按中心分组可能不合理 |
| 群组大小或密度差异很大 | 小群组可能被合并 |
| 需要直接发现异常点 | K-means通常会把异常点分入某组 |
| 数据没有统一尺度 | 大数值特征会控制结果 |
| 类别特征很多 | 距离和平均中心可能没有实际意义 |

# 14. 与相近算法比较

| 对比项 | K-means | DBSCAN | 层次聚类 |
|---|---|---|---|
| 输入形式 | 无答案的数值特征 | 无答案的数值特征 | 无答案的数值特征 |
| 输出形式 | 群组编号、群组中心 | 群组编号、异常点 | 群组编号、层级树 |
| 是否提前指定群组数 | 需要 | 不需要 | 建树时不需要 |
| 分组方式 | 反复调整群组中心 | 从密集区域扩展 | 逐步合并相近群组 |
| 不规则形状群组 | 较弱 | 强 | 可以处理 |
| 是否直接识别异常点 | 否 | 是 | 否 |
| 是否适合大数据 | 较好 | 视邻居搜索成本而定 | 较差 |
| 是否保证全局最优 | 否 | 不追求该目标 | 否 |
| 适用问题 | 中心明确的群组 | 不规则群组和异常点 | 群组层级分析 |

# 15. 可以与其他算法融合的位置

## 降维与K-means

```text
PCA等降维算法
  ↓ 输出较少的关键特征
K-means
  ↓ 输出群组编号和中心
业务分析
```

- **融合位置**：数据准备。
- **为什么融合**：特征过多会影响距离。
- **解决问题**：减少噪声和计算量。

## K-means++与K-means

```text
K-means++
  ↓ 提供较合理的初始中心
K-means
  ↓ 输出最终群组
```

- **融合位置**：初始中心生成。
- **为什么融合**：随机初始中心可能产生较差结果。
- **解决问题**：提高结果稳定性。

## K-means与监督学习

```text
K-means
  ↓ 输出群组编号或到各中心的距离
分类或回归算法
  ↓ 输出业务预测
```

- **融合位置**：特征生成。
- **为什么融合**：群组信息可以作为新特征。
- **解决问题**：让后续预测模型利用数据中的群体结构。

# 16. 最小示例

## 原始问题

把4个对象按一维位置分成两组。

## 输入数据

```text
1，2，8，9
```

## 变量或状态

- 输入：每个对象的位置；
- K值：2；
- 初始中心：1和8。

## 规则或约束

- 使用相同位置单位；
- 每个对象只能属于一个群组；
- 不提供正确分组答案。

## 目标

让对象尽量靠近所属群组的中心。

## 算法执行过程

```text
初始中心：
中心0 = 1
中心1 = 8

第一次分组：
群组0 = {1, 2}
群组1 = {8, 9}

更新中心：
中心0 = 1.5
中心1 = 8.5

再次分组：
结果没有变化，停止
```

## 输出结果

```text
群组0：1，2
群组1：8，9

群组中心：1.5，8.5
```

# 17. 一句话总结

> 人负责选择输入特征并指定群组数量K；`K-means`负责反复调整分组和群组中心；最终输出每个对象的群组编号及群组中心。
