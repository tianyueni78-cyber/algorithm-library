# DBSCAN
# 1. 一句话说明它是什么

> `DBSCAN` 是一种按照“附近是否聚集了足够多对象”自动分组的方法，主要用于发现形状不规则的群组，并找出孤立异常点。

DBSCAN属于**无监督学习**：历史数据不需要提供正确分组答案。

# 3. 人和算法分别负责什么

```text
现实问题
  ↓
人需要完成的工作
  ├── 选择用于比较对象的信息
  ├── 统一不同信息的数值尺度
  ├── 设置“多近算邻居”
  └── 设置“附近至少有多少对象才算聚集”
  ↓
算法需要完成的工作
  ├── 搜索每个对象附近的邻居
  ├── 从密集区域向外扩展群组
  ├── 给对象分配群组编号
  └── 标记无法归组的异常点
  ↓
最终结果
  ├── 每个对象的群组编号
  └── 异常点列表
```

- **人提供**：对象特征、邻域距离 `eps`、最少邻居数 `min_samples`。
- **算法完成**：搜索密集区域并自动形成群组。
- **算法返回**：群组编号、异常点以及核心点。

它不能自动解释每个群组的业务含义，也不会自动给群组命名。

# 5. 从抽象现实问题中提取模型的方法

```text
什么事情需要决定？
→ 每个对象属于哪个群组，或者是否为异常点

什么情况绝对不允许？
→ 不合理数据、禁止参与比较的信息、错误单位

什么结果算更好？
→ 同组对象彼此接近，不同组明显分开，结果符合业务常识

哪些信息在决策前已经知道？
→ 每个对象可以用于比较的特征

哪些信息会随着过程变化？
→ 新增对象、位置、行为和环境数据
```

| 自然语言关键词 | 对应内容 |
|---|---|
| “自动分组、发现群体” | 聚类输出 |
| “相似、靠近、附近” | 距离和输入特征 |
| “多近算邻居” | `eps` |
| “至少聚集多少个” | `min_samples` |
| “孤立、异常、离群” | 噪声点 |
| “位置、金额、频率、温度” | 输入数据 |

DBSCAN不是连续决策算法。数据发生变化后，通常需要重新运行。

# 6. 总体输入与输出

| 类型 | 内容 | 示例 |
|---|---|---|
| 原始业务输入 | 对象的原始记录 | 客户位置、消费频率、金额 |
| 建模后的算法输入 | 统一尺度的数字特征 | 每行代表一个客户 |
| 算法内部数据 | 邻居列表、访问状态、群组编号 | 客户A附近有5人 |
| 最终业务输出 | 群组及异常点 | 群组0、群组1、异常点 |

DBSCAN不需要历史正确答案。

# 7. 完整运行流程

```text

  ↓

  ↓

  ↓

  ↓

  ↓

```

# 9. 每个模块的输入、输出和构成

## 01_Problem_Data

### 作用

确定比较对象、输入特征和聚集标准。

### 输入

- 原始业务数据
- 业务中的“相似”标准

### 内部构成

```text
Problem_Data
├── Input_Features
├── Distance_Rule
└── DBSCAN_Parameters
```

### 处理过程

1. 确定需要分组的对象。
2. 选择能够代表相似性的特征。
3. 设置 `eps` 和 `min_samples`。

### 输出

- 特征列表
- 距离方式
- DBSCAN参数

### 是否需要用户自己实现

**通常需要自己完成。**

---

## 02_Data_Preparation

### 作用

把原始业务记录转换成可以公平比较的数字。

### 输入

- 原始数据
- 特征列表

### 内部构成

```text
Data_Preparation
├── Missing_Value_Handling
├── Category_Encoding
└── Feature_Scaling
```

### 处理过程

1. 处理缺失和错误数据。
2. 将必要的文字类别转换成数字。
3. 统一不同特征的数值尺度。

### 输出

- 处理后的特征表
- 数据转换规则

### 是否需要用户自己实现

**两者都可以。**软件库提供工具，人负责判断处理是否合理。

---

## 03_Clustering

### 作用

搜索密集区域并形成群组。

### 输入

- 处理后的特征表
- `eps`
- `min_samples`
- 距离方式

### 内部构成

```text
Clustering
├── Neighbor_Search
├── Core_Point_Check
└── Cluster_Expansion
```

“核心点”指附近拥有足够多邻居、可以继续扩展群组的对象。

### 处理过程

1. 选择一个尚未处理的对象。
2. 搜索它附近的邻居。
3. 邻居足够多时，从该对象开始建立群组。
4. 继续搜索邻居的邻居。
5. 无法加入任何群组的对象标记为异常点。

### 输出

- 每个对象的群组编号
- 核心点
- 异常点

### 是否需要用户自己实现

**通常由DBSCAN算法库提供。**

---

## 04_Result_Validation

### 作用

检查分组是否稳定并符合业务需求。

### 输入

- 原始对象
- 群组编号
- 异常点
- 不同参数下的运行结果

### 内部构成

```text
Result_Validation
├── Cluster_Statistics
├── Parameter_Comparison
└── Business_Interpretation
```

### 处理过程

1. 查看群组数量和大小。
2. 检查异常点数量。
3. 比较不同参数下的结果。
4. 根据业务信息解释各群组。

### 输出

- 群组统计
- 参数比较结果
- 业务群组名称

### 是否需要用户自己实现

**统计可由软件库提供；业务解释必须由人完成。**

# 11. 用户需要实现什么

## 通常需要自己实现

- 明确分组对象；
- 选择输入特征；
- 清理并统一数据；
- 选择距离方式；
- 设置和验证参数；
- 解释并命名群组；
- 判断异常点是否真的异常。

## 通常由算法库或求解器提供

- 计算对象之间的距离；
- 搜索附近邻居；
- 判断核心点；
- 扩展群组；
- 输出群组编号和异常点。

例如，`scikit-learn`提供DBSCAN计算，但不会自动解释群组的业务含义。

# 12. 它真正帮我解决什么

| 问题 | DBSCAN的边界 |
|---|---|
| 帮助理解问题吗？ | 能显示数据中的密集群体，但群组含义需要人解释。 |
| 帮助建立模型吗？ | 能建立聚类结果，但特征和参数需要人定义。 |
| 帮助搜索答案吗？ | 能搜索密集区域，不是排产或路径优化算法。 |
| 帮助预测结果吗？ | 通常不负责预测，也没有标准的新样本预测功能。 |
| 帮助做连续决策吗？ | 不能。数据变化后通常需要重新聚类。 |
| 帮助验证解是否可行吗？ | 不能保证业务正确，只能提供分组结果。 |

# 13. 适用与不适用场景

| 比较适合 | 原因 |
|---|---|
| 地理位置聚集分析 | 能发现不规则形状的群组 |
| 异常点发现 | 可以标记孤立对象 |
| 不知道群组数量 | 不需要提前指定分成几组 |
| 群组之间存在稀疏区域 | 容易根据密度分开 |

| 不太适合 | 原因 |
|---|---|
| 不同群组密度差异很大 | 一套参数难以同时适用 |
| 特征很多 | 距离可能失去区分能力 |
| 数据没有统一尺度 | 大数值特征会控制结果 |
| 需要预测新样本 | DBSCAN没有标准预测接口 |
| 数据量很大且邻居搜索昂贵 | 可能占用较多时间和内存 |

# 14. 与相近算法比较

| 对比项 | DBSCAN | K-Means | 层次聚类 |
|---|---|---|---|
| 输入 | 无答案的特征数据 | 无答案的特征数据 | 无答案的特征数据 |
| 输出 | 群组编号、异常点 | 群组编号、群组中心 | 群组层级关系 |
| 是否提前指定群组数 | 不需要 | 需要 | 切分结果时通常需要 |
| 分组依据 | 局部密集程度 | 距离群组中心的远近 | 对象或群组之间的距离 |
| 不规则形状群组 | 适合 | 较弱 | 可以处理 |
| 异常点处理 | 可直接标记 | 通常会强制归入某组 | 通常不会直接标记 |
| 是否保证业务正确 | 不保证 | 不保证 | 不保证 |
| 是否追求全局最优 | 否 | 通常只得到局部结果 | 否 |

# 15. 可以与其他算法融合的位置

## 降维与DBSCAN

```text
PCA等降维算法
  ↓ 输出较少的关键特征
DBSCAN
  ↓ 输出群组和异常点
业务分析
```

- **融合位置**：数据准备。
- **为什么融合**：特征过多会影响距离判断。
- **解决问题**：减少噪声和计算量。

## 参数搜索与DBSCAN

```text
邻居距离分析
  ↓ 提供eps候选值
DBSCAN
  ↓ 输出不同聚类结果
结果评价
```

- **融合位置**：参数选择。
- **为什么融合**：不同 `eps` 会产生不同群组。
- **解决问题**：减少完全依靠人工猜参数。

## DBSCAN与监督学习

```text
DBSCAN
  ↓ 输出群组编号或异常标记
分类或回归算法
  ↓ 输出预测结果
```

- **融合位置**：特征生成或数据清理。
- **为什么融合**：群组编号可作为新特征，异常点也可单独处理。
- **解决问题**：为后续预测提供数据结构信息。

# 16. 最小示例

## 原始问题

根据一维位置自动发现人群聚集区域。

## 输入数据

```text
1，2，8，9，20
```

## 变量或状态

- 输入：每个人的位置；
- `eps = 1.1`：距离不超过1.1算邻居；
- `min_samples = 2`：附近至少包含2个对象才形成密集区域。

## 规则或约束

- 位置使用相同单位；
- 不提供正确分组答案。

## 目标

找出聚集群体和孤立对象。

## 算法执行过程

```text
1和2距离较近 → 群组0
8和9距离较近 → 群组1
20附近没有足够邻居 → 异常点
```

## 输出结果

```text
位置1  → 群组0
位置2  → 群组0
位置8  → 群组1
位置9  → 群组1
位置20 → 异常点
```

# 17. 一句话总结

> 人负责选择比较特征并设置邻域参数；`DBSCAN`负责发现密集群组和孤立对象；最终输出群组编号及异常点。
