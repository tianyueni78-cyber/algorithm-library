# GSA（引力搜索算法）

# 1. 一句话说明它是什么

> GSA 是一种让较好方案产生更强吸引力、带动其他方案移动的优化算法，主要用于寻找较优的连续参数组合。

# 3. 人和算法分别负责什么

```text
现实问题
  ↓
人需要完成的工作
  ├── 定义需要调整的参数
  ├── 设置参数范围和约束
  └── 定义评价方法
  ↓
GSA需要完成的工作
  ├── 生成多组候选参数
  ├── 根据方案质量分配质量
  ├── 计算方案之间的吸引力
  └── 更新速度和位置
  ↓
最终结果
  └── 找到的最好参数及其评价值
```

GSA不会自动理解现实问题，也不会自动发现参数、目标和约束。

# 5. 从抽象现实问题中提取模型的方法

```text
什么事情需要决定？
→ 需要调整的参数

什么情况绝对不允许？
→ 参数边界和约束

什么结果算更好？
→ 目标函数

哪些信息已经知道？
→ 业务数据和固定参数

哪些信息会发生变化？
→ 环境、需求和设备状态
```

| 关键词 | 对应内容 |
|---|---|
| 调整、设置、比例、系数 | 决策变量 |
| 不能、必须、上限、下限 | 约束 |
| 最小、最大、更快、更省 | 目标 |
| 已知、给定、测量 | 输入数据 |

# 6. 总体输入与输出

| 类型 | 内容 | 示例 |
|---|---|---|
| 原始业务输入 | 设备或实验数据 | 速度、温度、误差 |
| 建模后的输入 | 参数范围、目标、约束 | 速度1～10 |
| 算法内部数据 | 位置、速度、质量、引力 | 多组候选参数 |
| 最终业务输出 | 最好参数和目标值 | 最佳速度7.2 |

这里的“质量”和“引力”只是算法内部数值：

```text
方案越好
→ 质量越大
→ 对其他方案吸引越强
```

# 7. 完整运行流程

```text
随机生成候选方案
  ↓
评价所有方案
  ↓
根据评分计算质量
  ↓
计算方案之间的引力
  ↓
计算加速度
  ↓
更新速度和位置
  ↓
处理边界与约束
  ↓
达到停止条件？
  ├── 否 → 继续
  └── 是 → 输出最好方案
```

# 9. 每个模块的输入、输出和构成

## 01_Problem_Data

### 作用

保存参数、范围、目标和约束。

### 输入

- 业务数据
- 参数边界
- 评价规则

### 内部构成

```text
Problem_Data
├── data
├── bounds
├── objective
└── constraints
```

### 处理过程

把现实问题整理成参数优化问题。

### 输出

- Problem对象

### 是否需要用户自己实现

通常需要自己实现。

## 02_Initialization

### 作用

生成初始候选方案。

### 输入

- 参数范围
- 个体数量

### 内部构成

```text
Initialization
├── create_positions()
├── create_velocities()
└── initialize_gravity()
```

### 处理过程

随机生成位置和初始速度。

### 输出

- 初始种群
- 初始引力常数

### 是否需要用户自己实现

算法库通常可以提供。

## 03_Evaluation

### 作用

评价每个候选方案。

### 输入

- 候选参数
- Problem

### 内部构成

```text
Evaluation
├── calculate_objective()
├── check_constraints()
└── rank_agents()
```

### 处理过程

计算目标值并检查约束。

### 输出

- 目标值
- 可行性结果
- 方案排名

### 是否需要用户自己实现

目标和约束通常需要自己实现。

## 04_Mass_Calculation

### 作用

根据方案质量分配质量。

### 输入

- 所有方案的目标值
- 当前最好值和最差值

### 内部构成

```text
Mass_Calculation
├── normalize_fitness()
└── calculate_mass()
```

### 处理过程

方案越好，获得的质量越大。

### 输出

- 每个方案的质量

### 是否需要用户自己实现

通常由算法库提供。

## 05_Force_And_Movement

### 作用

计算吸引力并更新方案位置。

### 输入

- 位置
- 速度
- 质量
- 引力常数

### 内部构成

```text
Force_And_Movement
├── calculate_force()
├── calculate_acceleration()
├── update_velocity()
├── update_position()
└── decay_gravity()
```

### 处理过程

```text
计算个体间引力
  ↓
合成总引力
  ↓
计算加速度
  ↓
更新速度
  ↓
更新位置
```

### 输出

- 新速度
- 新位置
- 新引力常数

### 是否需要用户自己实现

通常由算法库提供。

## 06_Constraint_Handling

### 作用

处理越界或违反规则的方案。

### 输入

- 新位置
- 参数边界
- 业务约束

### 内部构成

```text
Constraint_Handling
├── check_bounds()
├── repair()
└── penalty()
```

### 处理过程

对非法参数进行截断、修复或扣分。

### 输出

- 合法位置
- 或带惩罚的评分

### 是否需要用户自己实现

边界可由库处理；复杂约束通常需要自己实现。

## 07_Main_Solver

### 作用

控制GSA完整运行。

### 输入

- Problem
- GSA配置

### 内部构成

```text
Main_Solver
├── initialize()
├── evaluate()
├── calculate_mass()
├── calculate_force()
├── update_movement()
└── stop()
```

### 处理过程

重复评价、计算质量、计算引力和更新位置。

### 输出

- 最好参数
- 最好目标值
- 运行记录

### 是否需要用户自己实现

主框架通常由算法库提供。

# 12. 它真正帮我解决什么

| 问题 | GSA的作用 |
|---|---|
| 理解问题？ | 不能，人负责分析。 |
| 建立模型？ | 不能自动建立。 |
| 搜索答案？ | 是，这是主要作用。 |
| 预测结果？ | 不能，可与预测模型结合。 |
| 连续决策？ | 通常不是，环境变化后需重新运行。 |
| 验证可行性？ | 可以执行人定义的约束检查。 |

# 13. 适用与不适用场景

| 比较适合 | 原因 |
|---|---|
| 连续参数优化 | 可以直接移动参数 |
| 无法计算导数 | 只需评价方案 |
| 希望群体共同影响搜索 | 多个优秀个体可以产生吸引力 |

| 不太适合 | 原因 |
|---|---|
| 必须证明最优 | GSA通常不能证明 |
| 路径和排序问题 | 需要重新设计位置表示 |
| 评价成本很高 | 需要多轮评价种群 |

# 14. 与相近算法比较

| 对比项 | GSA | PSO | GWO |
|---|---|---|---|
| 移动依据 | 多个个体产生的引力 | 个体最好＋群体最好 | 当前前三名 |
| 个体质量 | 有 | 无 | 无 |
| 保存速度 | 是 | 是 | 否 |
| 适合变量 | 连续变量 | 连续变量 | 连续变量为主 |
| 保证最优 | 不保证 | 不保证 | 不保证 |

# 15. 可以与其他算法融合的位置

```text
预测模型
  ↓ 评价候选参数
GSA
  ↓ 找到较好参数
局部搜索
  ↓ 精细调整
最终方案
```

| 融合方式 | 位置 | 数据传递 | 作用 |
|---|---|---|---|
| GSA + 局部搜索 | 最终精调 | GSA输出最好方案 | 提高精度 |
| GSA + PSO | 速度更新 | PSO提供个体和群体经验 | 加快收敛 |
| GSA + DE | 新位置生成 | DE提供差分候选位置 | 增强多样性 |
| GSA + RL | 参数控制 | RL调整引力衰减参数 | 动态控制搜索 |

# 16. 最小示例

## 原始问题

调整机器速度，使产品误差最小。

## 输入数据

```text
速度范围：1～10
```

## 变量

```text
机器速度
```

## 规则

```text
速度不能超出1～10
```

## 目标

```text
产品误差最小
```

## 执行过程

```text
候选速度：3、6、9
  ↓
速度6的评分最好，质量最大
  ↓
速度3和9受到速度6较强吸引
  ↓
更新速度和位置
  ↓
重新评价
```

## 输出结果

```text
最好速度：约7.2
产品误差：当前最小值
```

# 17. 一句话总结

> 人负责定义参数、范围、约束和评价方法；GSA负责让较好方案以更大质量吸引其他方案移动；最终输出找到的较优参数。
