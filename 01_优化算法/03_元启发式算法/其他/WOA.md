# WOA（鲸鱼优化算法）

# 1. 一句话说明它是什么

> WOA 是一种让候选方案在“靠近最好方案、螺旋搜索和随机探索”之间切换的优化算法，主要用于寻找较优的连续参数组合。

# 3. 人和算法分别负责什么

```text
现实问题
  ↓
人需要完成的工作
  ├── 定义需要调整的参数
  ├── 设置参数范围和约束
  └── 定义评价方法
  ↓
WOA需要完成的工作
  ├── 生成多组候选参数
  ├── 找出当前最好方案
  ├── 靠近或围绕最好方案搜索
  └── 必要时转向随机方案探索
  ↓
最终结果
  └── 找到的最好参数及其评价值
```

WOA不会自动理解现实问题，也不会自动发现参数、目标和约束。

# 5. 从抽象现实问题中提取模型的方法

```text
什么事情需要决定？
→ 需要调整的参数

什么情况绝对不允许？
→ 参数边界和约束

什么结果算更好？
→ 目标函数

哪些信息已经知道？
→ 业务数据和固定参数

哪些信息会发生变化？
→ 环境、需求和设备状态
```

| 关键词 | 对应内容 |
|---|---|
| 调整、设置、比例、系数 | 决策变量 |
| 不能、必须、上限、下限 | 约束 |
| 最小、最大、更快、更省 | 目标 |
| 已知、给定、测量 | 输入数据 |

# 6. 总体输入与输出

| 类型 | 内容 | 示例 |
|---|---|---|
| 原始业务输入 | 设备或实验数据 | 速度、温度、误差 |
| 建模后的输入 | 参数范围、目标、约束 | 速度1～10 |
| 算法内部数据 | 鲸鱼位置、最好位置、搜索模式 | 多组候选参数 |
| 最终业务输出 | 最好参数和目标值 | 最佳速度7.2 |

鲸鱼位置就是一组候选参数，并不是真实位置。

# 7. 完整运行流程

```text
随机生成候选方案
  ↓
评价并记录最好方案
  ↓
选择更新方式
  ├── 靠近最好方案
  ├── 围绕最好方案螺旋移动
  └── 参考随机方案探索
  ↓
处理边界和约束
  ↓
重新评价
  ↓
达到停止条件？
  ├── 否 → 继续
  └── 是 → 输出最好方案
```

# 9. 每个模块的输入、输出和构成

## 01_Problem_Data

### 作用

保存参数、范围、目标和约束。

### 输入

- 业务数据
- 参数边界
- 评价规则

### 内部构成

```text
Problem_Data
├── data
├── bounds
├── objective
└── constraints
```

### 处理过程

把现实问题整理成参数优化问题。

### 输出

- Problem对象

### 是否需要用户自己实现

通常需要自己实现。

## 02_Initialization

### 作用

生成初始候选方案。

### 输入

- 参数范围
- 鲸鱼数量

### 内部构成

```text
Initialization
├── create_positions()
└── initialize_control_parameters()
```

### 处理过程

在参数范围内随机生成多组方案。

### 输出

- 初始鲸鱼种群

### 是否需要用户自己实现

算法库通常可以提供。

## 03_Evaluation

### 作用

评价所有候选方案。

### 输入

- 候选参数
- Problem

### 内部构成

```text
Evaluation
├── calculate_objective()
├── check_constraints()
└── update_best()
```

### 处理过程

计算目标值、检查约束并记录最好方案。

### 输出

- 目标值
- 可行性结果
- 当前最好方案

### 是否需要用户自己实现

目标和约束通常需要自己实现。

## 04_Search_Mode

### 作用

决定当前使用哪种搜索方式。

### 输入

- 当前迭代次数
- 搜索控制参数
- 随机数

### 内部构成

```text
Search_Mode
├── update_control_parameter()
├── select_encircling()
├── select_spiral()
└── select_random_search()
```

### 处理过程

根据控制参数在靠近、螺旋和随机搜索之间切换。

### 输出

- 当前搜索模式
- 当前控制参数

### 是否需要用户自己实现

通常由算法库提供。

## 05_Position_Update

### 作用

根据搜索模式更新参数。

### 输入

- 当前位置
- 最好位置
- 随机参考位置
- 搜索模式

### 内部构成

```text
Position_Update
├── move_toward_best()
├── spiral_around_best()
├── move_toward_random()
└── update_population()
```

### 处理过程

按照当前搜索模式计算新的候选位置。

### 输出

- 更新后的候选方案

### 是否需要用户自己实现

通常由算法库提供。

## 06_Constraint_Handling

### 作用

处理越界或违反规则的方案。

### 输入

- 新位置
- 参数边界
- 业务约束

### 内部构成

```text
Constraint_Handling
├── check_bounds()
├── repair()
└── penalty()
```

### 处理过程

对非法参数进行截断、修复或扣分。

### 输出

- 合法位置
- 或带惩罚的评分

### 是否需要用户自己实现

边界可由库处理；复杂约束通常需要自己实现。

## 07_Main_Solver

### 作用

控制WOA完整运行。

### 输入

- Problem
- WOA配置

### 内部构成

```text
Main_Solver
├── initialize()
├── evaluate()
├── select_mode()
├── update_positions()
├── update_best()
└── stop()
```

### 处理过程

重复评价、选择搜索模式和更新位置。

### 输出

- 最好参数
- 最好目标值
- 运行记录

### 是否需要用户自己实现

主框架通常由算法库提供。

# 12. 它真正帮我解决什么

| 问题 | WOA的作用 |
|---|---|
| 理解问题？ | 不能，人负责分析。 |
| 建立模型？ | 不能自动建立。 |
| 搜索答案？ | 是，这是主要作用。 |
| 预测结果？ | 不能，可与预测模型结合。 |
| 连续决策？ | 通常不是，环境变化后需重新运行。 |
| 验证可行性？ | 可以执行人定义的约束检查。 |

# 13. 适用与不适用场景

| 比较适合 | 原因 |
|---|---|
| 连续参数优化 | 可以直接移动参数 |
| 无法计算导数 | 只需评价方案 |
| 需要兼顾探索与精调 | 包含三种搜索方式 |

| 不太适合 | 原因 |
|---|---|
| 必须证明最优 | WOA通常不能证明 |
| 路径和排序问题 | 需要重新设计位置表示 |
| 评价成本很高 | 需要多轮评价种群 |

# 14. 与相近算法比较

| 对比项 | WOA | PSO | GWO |
|---|---|---|---|
| 搜索依据 | 最好方案或随机方案 | 自己最好＋群体最好 | 当前前三名 |
| 特殊操作 | 螺旋搜索 | 速度更新 | 三领导引导 |
| 保存速度 | 否 | 是 | 否 |
| 适合变量 | 连续变量 | 连续变量 | 连续变量为主 |
| 保证最优 | 不保证 | 不保证 | 不保证 |

# 15. 可以与其他算法融合的位置

```text
预测模型
  ↓ 评价候选参数
WOA
  ↓ 找到较好参数
局部搜索
  ↓ 精细调整
最终方案
```

| 融合方式 | 位置 | 数据传递 | 作用 |
|---|---|---|---|
| WOA + 局部搜索 | 最终精调 | WOA输出最好方案 | 提高精度 |
| WOA + DE | 随机探索 | DE提供差分候选位置 | 增强多样性 |
| WOA + PSO | 位置更新 | PSO提供历史经验 | 加快收敛 |
| WOA + RL | 模式选择 | RL选择搜索方式 | 动态控制搜索 |

# 16. 最小示例

## 原始问题

调整机器速度，使产品误差最小。

## 输入数据

```text
速度范围：1～10
```

## 变量

```text
机器速度
```

## 规则

```text
速度不能超出1～10
```

## 目标

```text
产品误差最小
```

## 执行过程

```text
候选速度：3、6、9
  ↓
当前最好速度：6
  ↓
部分方案靠近6
部分方案围绕6搜索
部分方案参考随机位置探索
  ↓
重新评价
```

## 输出结果

```text
最好速度：约7.2
产品误差：当前最小值
```

# 17. 一句话总结

> 人负责定义参数、范围、约束和评价方法；WOA负责在靠近最好方案、螺旋搜索和随机探索之间切换；最终输出找到的较优参数。
