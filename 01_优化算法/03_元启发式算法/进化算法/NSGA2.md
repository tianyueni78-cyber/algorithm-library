# NSGA-II（非支配排序遗传算法2）

# 1. 一句话说明它是什么

> NSGA-II 是一种同时搜索多个冲突目标的进化算法，主要用于找出一组各有取舍的优秀方案。

例如同时优化：

```text
成本更低
时间更短
能耗更少
```

它通常输出多个折中方案，而不是唯一答案。

# 3. 人和算法分别负责什么

```text
现实问题
  ↓
人需要完成的工作
  ├── 决定需要优化什么
  ├── 定义多个目标和约束
  ├── 设计方案编码
  └── 设置种群大小和迭代次数
  ↓
NSGA-II需要完成的工作
  ├── 生成多种方案
  ├── 计算每个方案的多个目标值
  ├── 将方案按优劣关系分层
  ├── 保留优秀且差异较大的方案
  └── 通过交叉、变异继续搜索
  ↓
最终结果
  └── 一组可供选择的折中方案
```

人提供问题模型；NSGA-II负责搜索；最后仍由人选择最符合现实需要的方案。

# 5. 从抽象现实问题中提取模型的方法

```text
什么事情需要决定？
→ 决策变量或染色体

什么情况绝对不允许？
→ 约束和可行性规则

哪些结果都希望变好？
→ 多个目标函数

哪些信息已经知道？
→ 输入数据和固定参数

哪些信息会发生变化？
→ 新任务、故障、价格、需求
```

| 自然语言关键词 | 对应内容 |
|---|---|
| 选择、安排、顺序、分配 | 决策变量 |
| 必须、不能、最多、至少 | 约束 |
| 更快、更省、更稳、更均衡 | 目标 |
| 已知、给定、现有 | 输入数据 |

# 6. 总体输入与输出

| 类型 | 内容 | 示例 |
|---|---|---|
| 原始业务输入 | 现实中的已知数据 | 订单、机器、加工时间 |
| 建模后的输入 | 编码、约束、多个目标 | 时间最短、能耗最低 |
| 算法内部数据 | 种群、等级、拥挤距离 | 当前100个候选方案 |
| 最终业务输出 | 一组折中方案 | 快速方案、节能方案、平衡方案 |

# 7. 完整运行流程

```text
现实问题
  ↓
定义编码、目标和约束
  ↓
生成初始种群
  ↓
计算所有方案的目标值
  ↓
非支配排序
  ↓
计算拥挤距离
  ↓
选择父代
  ↓
交叉和变异
  ↓
父代与子代合并
  ↓
选择下一代
  ↓
达到停止条件？
  ├── 否 → 继续循环
  └── 是 → 输出第一层方案
```

两个核心操作：

- 非支配排序：把更优秀的方案放在更靠前的层。
- 拥挤距离：同一层中优先保留与其他方案差异较大的方案。

# 9. 每个模块的输入、输出和构成

## 01_Problem_Data

### 作用

保存问题数据、目标和约束。

### 输入

- 原始数据
- 业务规则
- 多个优化目标

### 内部构成

```text
Problem_Data
├── input_data
├── objectives
└── constraints
```

### 处理过程

读取、检查并整理业务数据。

### 输出

- Problem对象

### 是否需要用户自己实现

通常需要自己实现。

## 02_Encoding

### 作用

在现实方案和染色体之间转换。

### 输入

- Problem
- 现实方案或染色体

### 内部构成

```text
Encoding
├── encode()
├── decode()
└── repair()
```

### 处理过程

编码方案、还原方案并修复非法方案。

### 输出

- 染色体
- 现实方案

### 是否需要用户自己实现

通常需要自己实现。

## 03_Initialization

### 作用

生成第一批候选方案。

### 输入

- Problem
- 种群规模

### 内部构成

```text
Initialization
├── random_initialize()
└── heuristic_initialize()
```

### 处理过程

随机生成或利用规则生成多个方案。

### 输出

- 初始种群

### 是否需要用户自己实现

两者都可以。

## 04_Objective_Evaluation

### 作用

计算每个方案的多个目标值。

### 输入

- 候选方案
- Problem

### 内部构成

```text
Objective_Evaluation
├── decode()
├── calculate_objectives()
└── check_constraints()
```

### 处理过程

还原方案，计算时间、成本等目标，并检查约束。

### 输出

- 多个目标值
- 可行性结果

### 是否需要用户自己实现

通常需要自己实现。

## 05_Nondominated_Sorting

### 作用

按照方案之间的优劣关系进行分层。

### 输入

- 种群
- 每个方案的目标值

### 内部构成

```text
Nondominated_Sorting
├── compare_dominance()
├── find_fronts()
└── assign_rank()
```

### 处理过程

```text
没有被其他方案全面超过
→ 第一层

只被第一层方案超过
→ 第二层

依次继续分层
```

### 输出

- 多个非支配层
- 每个方案的等级

### 是否需要用户自己实现

算法库通常提供。

## 06_Crowding_Distance

### 作用

避免方案全部集中在相似区域。

### 输入

- 同一非支配层
- 目标值

### 内部构成

```text
Crowding_Distance
├── sort_by_objective()
├── calculate_distance()
└── assign_distance()
```

### 处理过程

比较每个方案与相邻方案的距离，距离大表示该方案周围较空。

### 输出

- 每个方案的拥挤距离

### 是否需要用户自己实现

算法库通常提供。

## 07_Genetic_Operators

### 作用

选择父代并产生新方案。

### 输入

- 当前种群
- 等级
- 拥挤距离
- 交叉率和变异率

### 内部构成

```text
Genetic_Operators
├── tournament_selection()
├── crossover()
├── mutation()
└── repair()
```

### 处理过程

优先选择等级低、拥挤距离大的方案，然后交叉和变异。

### 输出

- 子代种群

### 是否需要用户自己实现

通用算子由算法库提供；特殊编码通常需要自己实现。

## 08_Main_Solver

### 作用

控制NSGA-II的完整运行。

### 输入

- Problem
- NSGA-II配置

### 内部构成

```text
Main_Solver
├── initialize()
├── evaluate()
├── sort()
├── calculate_distance()
├── reproduce()
├── environmental_selection()
└── stop()
```

### 处理过程

反复执行评价、排序、选择、交叉、变异和下一代更新。

### 输出

- 第一非支配层
- 所有折中方案
- 每个方案的目标值

### 是否需要用户自己实现

主框架可由算法库提供，问题相关部分需要用户实现。

# 12. 它真正帮我解决什么

| 问题 | NSGA-II的作用 |
|---|---|
| 帮助理解问题？ | 不能，现实问题由人分析。 |
| 帮助建立模型？ | 不能自动建模，人必须定义变量、目标和约束。 |
| 帮助搜索答案？ | 是，主要负责搜索多个折中方案。 |
| 帮助预测结果？ | 不能，但可以调用预测模型。 |
| 帮助连续决策？ | 原始算法主要解决一次性优化，环境变化后通常需要重新运行。 |
| 帮助验证可行性？ | 可以执行人定义的检查规则，但不会自动发现规则。 |

# 13. 适用与不适用场景

| 比较适合 | 原因 |
|---|---|
| 两三个冲突目标 | 能同时搜索多种取舍 |
| 调度、路径、资源分配 | 方案数量通常很大 |
| 不确定各目标权重 | 不必提前合成一个总分 |
| 希望获得不同类型方案 | 拥挤距离帮助保持多样性 |

| 不太适合 | 原因 |
|---|---|
| 只有一个目标 | 普通GA更简单 |
| 必须证明最优 | NSGA-II通常不能证明 |
| 目标数量非常多 | NSGA-III通常更合适 |
| 一次评价成本很高 | 需要评价大量方案 |

# 15. 可以与其他算法融合的位置

```text
贪心算法
  ↓ 生成较好的初始方案
NSGA-II
  ↓ 输出多组折中方案
局部搜索
  ↓ 精细改进
最终方案集
```

| 融合方式 | 融合位置 | 数据传递 | 解决的问题 |
|---|---|---|---|
| NSGA-II + 贪心 | 初始化 | 贪心输出初始方案 | 提高起点质量 |
| NSGA-II + 局部搜索 | 子代优化 | 子代输入局部搜索 | 提高方案精度 |
| NSGA-II + CP/MILP | 修复或补全 | 部分方案输入求解器 | 处理复杂约束 |
| NSGA-II + RL | 参数或算子选择 | RL输出交叉、变异策略 | 动态调节搜索 |
| NSGA-II + 预测模型 | 目标评价 | 模型预测方案效果 | 降低评价成本 |

# 16. 最小示例

## 原始问题

选择一个运输方案，同时希望时间短、成本低。

## 输入数据

| 方案 | 时间 | 成本 |
|---|---:|---:|
| A | 2小时 | 100元 |
| B | 3小时 | 70元 |
| C | 4小时 | 90元 |
| D | 5小时 | 60元 |

## 变量

```text
选择哪个运输方案
```

## 规则

```text
只能选择一个方案
```

## 目标

```text
目标1：时间最短
目标2：成本最低
```

## 算法执行过程

```text
比较四个方案
  ↓
C比B更慢而且更贵
  ↓
C被B支配，进入较差层
  ↓
A、B、D互有优缺点，进入第一层
```

## 输出结果

```text
第一非支配层
├── A：最快，但最贵
├── B：时间和成本较平衡
└── D：最便宜，但最慢
```

NSGA-II不会替用户决定最终选A、B还是D。

# 17. 一句话总结

> 人负责定义方案、约束和多个目标；NSGA-II负责把方案分层并保留优秀且分散的方案；最终输出一组可供选择的折中方案。
