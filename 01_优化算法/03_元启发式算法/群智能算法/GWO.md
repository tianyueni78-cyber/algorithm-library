# GWO（灰狼优化算法）

# 1. 一句话说明它是什么

> GWO 是一种让所有候选方案同时参考当前前三名方案移动的优化算法，主要用于寻找较优的连续参数组合。

# 3. 人和算法分别负责什么

```text
现实问题
  ↓
人需要完成的工作
  ├── 定义需要调整的参数
  ├── 设置参数范围和约束
  └── 定义评价方法
  ↓
GWO需要完成的工作
  ├── 生成多组候选参数
  ├── 找出当前前三名方案
  ├── 让其他方案参考前三名移动
  └── 逐渐缩小搜索范围
  ↓
最终结果
  └── 找到的最好参数及其评价值
```

GWO不会自动理解现实问题，也不会自动发现参数、目标和约束。

# 5. 从抽象现实问题中提取模型的方法

```text
什么事情需要决定？
→ 需要调整的参数

什么情况绝对不允许？
→ 参数边界和约束

什么结果算更好？
→ 目标函数

哪些信息已经知道？
→ 业务数据和固定参数

哪些信息会发生变化？
→ 环境、需求和设备状态
```

| 关键词 | 对应内容 |
|---|---|
| 调整、设置、比例、系数 | 决策变量 |
| 不能、必须、上限、下限 | 约束 |
| 最小、最大、更快、更省 | 目标 |
| 已知、给定、测量 | 输入数据 |

# 6. 总体输入与输出

| 类型 | 内容 | 示例 |
|---|---|---|
| 原始业务输入 | 设备或实验数据 | 速度、温度、误差 |
| 建模后的输入 | 参数范围、目标、约束 | 速度1～10 |
| 算法内部数据 | 狼群位置、评分、前三名 | 多组候选参数 |
| 最终业务输出 | 最好参数和目标值 | 最佳速度7.2 |

前三名分别称为：

```text
Alpha：第一名
Beta：第二名
Delta：第三名
```

其余候选方案称为 Omega。

# 7. 完整运行流程

```text
随机生成狼群位置
  ↓
评价所有方案
  ↓
确定Alpha、Beta、Delta
  ↓
其他方案参考前三名更新位置
  ↓
处理边界和约束
  ↓
逐渐缩小搜索范围
  ↓
达到停止条件？
  ├── 否 → 继续
  └── 是 → 输出Alpha方案
```

# 9. 每个模块的输入、输出和构成

## 01_Problem_Data

### 作用

保存参数、范围、目标和约束。

### 输入

- 业务数据
- 参数边界
- 评价规则

### 内部构成

```text
Problem_Data
├── data
├── bounds
├── objective
└── constraints
```

### 处理过程

把现实问题整理成参数优化问题。

### 输出

- Problem对象

### 是否需要用户自己实现

通常需要自己实现。

## 02_Initialization

### 作用

生成初始候选方案。

### 输入

- 参数范围
- 狼群数量

### 内部构成

```text
Initialization
├── create_wolves()
└── initialize_control_parameter()
```

### 处理过程

在参数范围内随机生成多组方案。

### 输出

- 初始狼群

### 是否需要用户自己实现

算法库通常可以提供。

## 03_Evaluation

### 作用

评价每只狼代表的方案。

### 输入

- 候选参数
- Problem

### 内部构成

```text
Evaluation
├── calculate_objective()
├── check_constraints()
└── rank_wolves()
```

### 处理过程

计算目标值、检查约束并排列方案。

### 输出

- 目标值
- 可行性结果
- 方案排名

### 是否需要用户自己实现

目标和约束通常需要自己实现。

## 04_Leader_Selection

### 作用

找出当前前三名方案。

### 输入

- 已评价的狼群

### 内部构成

```text
Leader_Selection
├── select_alpha()
├── select_beta()
└── select_delta()
```

### 处理过程

根据评分确定第一、第二和第三名。

### 输出

- Alpha方案
- Beta方案
- Delta方案

### 是否需要用户自己实现

通常由算法库提供。

## 05_Position_Update

### 作用

让其他方案参考前三名移动。

### 输入

- 当前方案
- Alpha、Beta、Delta
- 当前搜索控制参数

### 内部构成

```text
Position_Update
├── calculate_alpha_position()
├── calculate_beta_position()
├── calculate_delta_position()
└── combine_positions()
```

### 处理过程

分别计算向前三名移动后的候选位置，再合成新位置。

### 输出

- 更新后的候选方案

### 是否需要用户自己实现

通常由算法库提供。

## 06_Constraint_Handling

### 作用

处理越界或违反规则的方案。

### 输入

- 新候选方案
- 参数边界
- 业务约束

### 内部构成

```text
Constraint_Handling
├── check_bounds()
├── repair()
└── penalty()
```

### 处理过程

对非法参数进行截断、修复或扣分。

### 输出

- 合法方案
- 或带惩罚的评分

### 是否需要用户自己实现

边界可由库处理；复杂约束通常需要自己实现。

## 07_Main_Solver

### 作用

控制GWO完整运行。

### 输入

- Problem
- GWO配置

### 内部构成

```text
Main_Solver
├── initialize()
├── evaluate()
├── select_leaders()
├── update_positions()
├── update_control_parameter()
└── stop()
```

### 处理过程

重复评价、确定前三名和更新狼群位置。

### 输出

- Alpha方案
- 最好目标值
- 运行记录

### 是否需要用户自己实现

主框架通常由算法库提供。

# 12. 它真正帮我解决什么

| 问题 | GWO的作用 |
|---|---|
| 理解问题？ | 不能，人负责分析。 |
| 建立模型？ | 不能自动建立。 |
| 搜索答案？ | 是，这是主要作用。 |
| 预测结果？ | 不能，可与预测模型结合。 |
| 连续决策？ | 通常不是，环境变化后需重新运行。 |
| 验证可行性？ | 可以执行人定义的约束检查。 |

# 13. 适用与不适用场景

| 比较适合 | 原因 |
|---|---|
| 连续参数优化 | 可以直接移动参数 |
| 不需要或没有导数 | 只需评价方案 |
| 希望算法结构简单 | 主要依靠前三名方案 |

| 不太适合 | 原因 |
|---|---|
| 必须证明最优 | GWO通常不能证明 |
| 路径和排序问题 | 需要重新设计位置表示 |
| 评价成本很高 | 需要多轮评价狼群 |

# 14. 与相近算法比较

| 对比项 | GWO | PSO | FA |
|---|---|---|---|
| 移动依据 | 同时参考前三名 | 参考自身和群体最好位置 | 向更亮方案移动 |
| 历史速度 | 不保存 | 保存速度 | 不保存 |
| 适合变量 | 连续变量为主 | 连续变量 | 连续变量为主 |
| 保证最优 | 不保证 | 不保证 | 不保证 |

# 15. 可以与其他算法融合的位置

```text
预测模型
  ↓ 评价候选参数
GWO
  ↓ 找到较好参数
局部搜索
  ↓ 精细调整
最终方案
```

| 融合方式 | 位置 | 数据传递 | 作用 |
|---|---|---|---|
| GWO + 局部搜索 | 最终精调 | GWO输出Alpha方案 | 提高精度 |
| GWO + DE | 位置更新 | DE提供差分候选方案 | 增强搜索多样性 |
| GWO + RL | 参数控制 | RL输出搜索控制参数 | 动态调节搜索 |
| GWO + CP/MILP | 约束修复 | GWO输出候选方案 | 处理复杂约束 |

# 16. 最小示例

## 原始问题

调整机器速度，使产品误差最小。

## 输入数据

```text
速度范围：1～10
```

## 变量

```text
机器速度
```

## 规则

```text
速度不能超出1～10
```

## 目标

```text
产品误差最小
```

## 执行过程

```text
候选速度：3、6、8、9
  ↓
前三名：6、8、9
  ↓
其他方案参考这三个速度移动
  ↓
重新评价并更新前三名
```

## 输出结果

```text
Alpha速度：约7.2
产品误差：当前最小值
```

# 17. 一句话总结

> 人负责定义参数、范围、约束和评价方法；GWO负责让所有候选方案参考当前前三名移动；最终输出找到的较优参数。
